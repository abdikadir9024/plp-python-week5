# Countdown, Guessing Game & Loop Patterns

This repository contains Python solutions practicing `while` and `for` loops for PLP Python Week 5.

## Files Description
* `countdown.py`: Uses a `while` loop to count down from a user-specified number to 1 and prints "Blast off!".
* `guess_game.py`: Interactive number guessing game with hint feedback ("Too high!" / "Too low!") and attempt tracking using a `while` loop.
* `spell_it_out.py`: Demonstrates `for` loops by iterating through characters in a string, printing numbered indices, and providing total word length.

## Reflection: When to use `while` vs `for` loops
I reach for a `for` loop when the number of iterations is known in advance or when iterating through a fixed sequence like a string or list. On the other hand, I use a `while` loop when code needs to repeat until a specific condition is met, especially when user input determines when the loop should end.
